# Contributing — Brand Site

Статический сайт бренда Atomic (`*.dc.html` + React-вендор + дизайн-система в `_ds/`).
Деплой — на AlphaVPS в `/var/www/atomic`, отдаётся Caddy (`atomic-automation.net`).

> ⚠️ **Этот каталог пока НЕ под git.** Первый шаг здорового прода — `git init` + приватный
> remote. До этого правила ниже — договорённость, а не enforced-регламент.

## 1. Перед любой правкой — бэкап

Каталог уже бэкапится в `brand-site.bak/` (sibling) и `Бренд сайт с анимациями.zip`.
Перед правкой контента убедись, что актуальный бэкап есть. Ни один оригинал не удаляем на месте.

## 2. Что правим и что нет

- **Контент и расположение** существующих элементов на страницах (`index.dc.html`,
  `atomic-intel.dc.html`, `atomic-engage.dc.html`, `atomic-vault.dc.html`, `docs.dc.html`) — да.
- **Дизайн-систему** (`_ds/atomic-design-system-*/`, `styles.css`, токены) — не ломаем;
  правки согласуются отдельно. `_adherence.oxlintrc.json` — гейт соответствия, не обходить.
- Ассеты (`assets/logo`, `assets/graphics`) — не переименовываем без обновления ссылок.

## 3. Проверка перед публикацией

```bash
# локальный предпросмотр
cd brand-site && python -m http.server 8123
# открыть каждую страницу, проверить, что ничего не разъехалось
```

- [ ] Все 5 страниц открываются, ссылки/ассеты не битые.
- [ ] Вёрстка не разъехалась на мобильном (один столбец, крупный текст).
- [ ] Скорость загрузки не деградировала (см. `OPTIMIZATION.md`: babel/вендор не тянуть лишний раз).
- [ ] Нет случайно закоммиченных `uploads/` с приватными заметками, если они не для публикации.

## 4. Деплой

Собранные страницы копируются в `/var/www/atomic` на AlphaVPS. Деплой — вручную владельцем
после ревью изменений. Секретов на статике быть не должно.
