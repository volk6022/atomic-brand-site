# ATOMIC — дизайн-система

ATOMIC — бренд автоматизации бизнеса (Омск/Россия, рынок RU). Три продукта:

- **Atomic Intel** — поиск клиентов, парсинг (Яндекс.Карты и др.), обогащение данных, мониторинг сайтов с LLM-анализом и уведомлениями (Telegram, webhook).
- **Atomic Engage** — автоматизация действий в Telegram через личный аккаунт: первые касания, follow-up, мониторинг каналов, сценарии.
- **Atomic Vault** — локальная база знаний, спроектированная для работы с LLM (в т.ч. локальными); открытая структура на GitHub, продаётся внедрение.

Позиционирование: «blue ocean» — новая ниша с малой конкуренцией; прозрачность, понятность, отсутствие лишней сложности. Архетипы из мудборда: Маг / Мудрец. Форматы коммуникации: профили на kwork/fl.ru, персональные письма в Telegram (коротко, без вложений), email с компактным PDF (1–2 стр. A4), сайт бренда.

## CONTENT FUNDAMENTALS

- Язык — русский; латиница для названия ATOMIC и продуктов (Atomic Intel/Engage/Vault) и технических вставок.
- Тон: спокойный, объясняющий, без хайпа. «Мы создаём понятные инструменты, которые решают конкретные задачи бизнеса». Обещание пользы, не магии — хотя архетип «Маг»: результат выглядит волшебно, объяснение простое.
- Обращение: «мы» о бренде, «вы» к клиенту. Без эмодзи. Без англицизмов, где есть русское слово; технические термины (enrichment, webhook, LLM) допустимы как термины.
- Тексты короткие; в Telegram — очень короткие персональные письма без вложений.
- Микроподписи в JetBrains Mono, нижний регистр или РАЗРЯДКА КАПСОМ, «·» как разделитель: `интеллект · данные · системы`.

## VISUAL FOUNDATIONS

- **Цвет** (точно из Figma): cream `#F8F3E0` (фон), navy `#131E5F` (лого и заголовки), teal `#94BEBE`, sea `#156479` (+вариант 64% прозрачности), deep `#184153` (текст на светлом), ember `#DA501C` (редкий акцент), gray `#D9D9D9`. Производные светлые тона (ice/mist/foam) добавлены для направления «океан/прозрачность» — помечены DERIVED в `tokens/colors.css`.
- **Правило цвета по фонам**:
  - на молочно-белом (cream) фоне: оранжевый (ember) и синий (navy) — для текста и элементов; teal — ТОЛЬКО для элементов и аккуратно (как текст нечитаем).
  - на оранжевом (ember) фоне: синий (navy) и белый.
  - на синем (navy/sea) фоне: оранжевый (ember) и teal.
  - на teal фоне: тёмно-синий (navy); белый — аккуратно, для разнообразия.
- **Тип**: Architexture (400) — основной шрифт: заголовки и текст; JetBrains Mono — код и технические подписи. Вариант заголовков — **Unifix** (`--font-display-alt`), дисплейное начертание для латинских заголовков (ATOMIC, названия продуктов). Размеры 48/40/32/15, line-height 100% на заголовках.
- **Композиция**: бауhaus-блоки — крупные прямоугольные плоскости цвета по краю холста (см. Frame 4/14/15), контент от левого поля ~92–150px. Прямые углы у плоскостей; скругления только в графике (капсула знака).
- **Графика**: знак = капсула-контур + узлы-точки + линии-связи («молекула/схема»). Фирменная графика — **циркуитные мотивы** (`assets/graphics/circuit-*.svg`): капсулы-контейнеры, узлы-точки, прямоугольные связи и разводки — производные от знака. Монохромные SVG, перекрашиваются через CSS `mask` + `background-color`. Муаровая графика больше не используется (отменена). Технические элементы неброские: mono-подписи, координаты.
- **Прозрачность**: полупрозрачные слои teal/sea (24/48/64%) поверх светлого — «толща воды»; blur умеренно.
- **Тени**: почти нет; плоская графика. Карточки — плоские плоскости цвета, без радиуса.
- **Анимация**: не определена в источнике — по умолчанию сдержанные fade/сдвиги, без bounce.
- **Изображения**: в мудборде — Bauhaus-постеры, сети/ризомы, line-art. Фотографии не используются.

## ICONOGRAPHY

Иконок в источнике нет. Не изобретать иконки: использовать узлы-точки, линии-связи и mono-символы (`→ · ● $ [ ]`) как функциональные маркеры. Если понадобится набор иконок — согласовать отдельно (ближайший по духу: тонкие геометричные линии 2–2.5px).

Логотип — **новая вёрстка** (точные векторы из Figma, Frame 4): знак-схема (капсула + узлы + T-разводка) над словесным знаком ATOMIC, ниже — подпись «Автоматизация бизнеса». `assets/logo/` — lockup / wordmark / mark × navy / cream / ember. Монограммы (2 варианта): `atomic-monogram-a` (схема-интерлейс) и `atomic-monogram-b` (сплошной знак), каждая в основной и инверсной раскладке (`-inv`).

## Индекс

- `styles.css` → `tokens/` (fonts, colors, typography, spacing)

- UI-китов нет: продукты пока без готовых интерфейсов в источниках.
